    Clé Google Maps

    La clé reste dans le stockage local de ce navigateur. Elle n'est jamais envoyée ailleurs qu'à Google, et elle n'est pas enregistrée dans le dépôt.

    Restreins cette clé avant de t'en servir : dans Google Cloud, limite-la au référent HTTP de ce site et n'autorise que Maps JavaScript API, Places API (New) et Geocoding API. Sans restriction, une clé publiée est utilisable par n'importe qui, à tes frais.
    1. Console Google Cloud → APIs & Services → Credentials.
    2. Active les trois API ci-dessus sur le projet.
    3. Crée une clé, puis Application restrictions → Websites → ajoute ce domaine.
    4. Colle la clé ici. Chaque balayage compte pour une requête facturée.
